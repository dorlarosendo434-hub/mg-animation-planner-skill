# 垫图规划、生成与自动编号

只在需要生成或整理图片素材时读取本文件。

## 先分三类

### 透明主体图

适合人物、器物、动植物、图标、内容卡片和机制装置。要求：

- 真透明背景；
- 四周留足移动空间；
- 主体完整，不裁切；
- 不带文字、编号、Logo和水印；
- 发光可以保留，但边缘不能有不透明黑底。

### 完整场景图

适合开场、环境、空间关系、情绪转折和收束。要求：

- 按目标画幅构图；
- 人物、标题区和运动路径位于安全区；
- 不在画面里预先生成字幕；
- 可作为首帧或尾帧时，必须标出配对关系。

### 纯MG元素

箭头、时间轴、路径、描边框、简单折线、字幕和图标标签优先由视频平台或代码生成，不必全部做成垫图。

## 首尾帧配对

需要连续变化时，先生成首帧，再以首帧为参考编辑尾帧。尾帧提示词明确写：保持人物身份、服装、姿势、机位、透视和场景几何不变，只改变指定状态。

常见配对：

- 环境平静 → 机制显现；
- 一个对象 → 大量相似对象；
- 闭合/收缩 → 展开/开放；
- 实验开始 → 实验结果；
- 远景建立 → 同场景近景或结束状态。

## 编号规则

编号在生成前确定，提示词、清单和文件只共享一套编号：

```text
图片01.png
图片02.png
...
图片21.png
```

文件名不追加“P01”“首帧”“透明”或中文描述。说明写入`00_图片编号清单.md`。

## 打包清单JSON

`package_mg_assets.ps1`读取JSON数组。`index`必须从1连续递增；`kind`只能为`transparent`或`scene`。

```json
[
  {
    "index": 1,
    "source": "C:\\path\\character.png",
    "kind": "transparent",
    "label": "手持手机的主人公"
  },
  {
    "index": 2,
    "source": "C:\\path\\opening.png",
    "kind": "scene",
    "label": "开场完整场景"
  }
]
```

运行示例：

```powershell
& "C:\Users\<用户名>\.codex\skills\mg-animation-planner\scripts\package_mg_assets.ps1" `
  -ManifestPath "C:\project\manifest.json" `
  -OutputDir "C:\project\final-assets" `
  -AspectRatio "<16:9|9:16|4:3|3:4|1:1>" `
  -CreateZip
```

画幅默认尺寸：

- `9:16` → 1080×1920；
- `16:9` → 1920×1080；
- `4:3` → 1440×1080；
- `3:4` → 1080×1440；
- `1:1` → 1080×1080。

透明素材原样复制以保留Alpha；完整场景居中裁切并转为不透明PNG。若目标文件已存在，脚本默认停止；只有明确允许覆盖本次生成物时才使用`-Force`。

## 图片生成提示词要点

透明素材提示词至少写明：用途、单一主体、完整轮廓、四周留白、真透明背景、禁止文字与Logo。

完整场景提示词至少写明：目标画幅、主体位置、标题留白、安全区、空间层次、灯光、禁止文字与Logo。

人物一致性提示词明确写：参考图角色身份不变，保留脸、发型、服装、体型和配色；只改变场景或动作。连续场景不要仅用文字重新生成角色。

## 生成后的检查

- 透明图实际含Alpha，角落不是假黑底；
- 完整场景尺寸一致且不透明；
- 人物没有多手、多指、断肢或换脸；
- 重要主体未贴边；
- 图片内没有乱码和随机Logo；
- 首尾帧人物、机位和空间连续；
- 图片编号与完整提示词逐项对应。
