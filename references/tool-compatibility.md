# 工具兼容与交付适配

只在用户指定生成平台、询问用什么工具，或准备把素材包投入制作时读取本文件。

## 首选路径一：Fotor直接制作MG动效

Fotor适合直接消费本Skill输出的完整提示词和编号图片。

推荐交付：

- `00_完整提示词.md`；
- `00_旁白字幕稿.md`；
- `图片01.png—图片NN.png`；
- 明确的首帧/尾帧配对；
- 画幅、时长、字体、配乐和转场要求。

适配时：

- 在提示词中使用“图片01”“图片02”等与文件名完全相同的引用；
- 连续镜头优先把首尾帧成对上传；
- 透明主体图用于独立图层运动，完整场景用于环境、机位和情绪；
- 把文字、字幕、形状、图表和数据可视化交给可编辑MG图层；
- 平台支持的单次图片数量不足时，按片段分批上传，但保留全局编号。

官方入口：

- Fotor AI Motion Graphics Generator: https://www.fotor.com/ai-video-generator/motion-graphics/
- Fotor Video Agent: https://www.fotor.com/video/

## 首选路径二：Claude Opus 5类模型＋代码转视频

Claude Opus 5及同类高能力模型适合解释结构化分镜、生成动画代码、维护跨片段状态并迭代细节。它们需要搭配可执行或渲染环境，例如：

- HTML/CSS/SVG；
- Canvas/WebGL；
- Remotion；
- 其他代码转视频或前端动画工程。

推荐交付：

- 完整提示词与旁白稿；
- 图片编号清单与本地素材路径；
- 每个片段的开始时间、结束时间和动画阶段；
- 画布尺寸、字体与安全区；
- 首尾帧连续性和不可改变项；
- 导出目标，例如MP4、WebM或PNG序列。

适配提示词要明确要求模型：

1. 先建立统一画布、时间轴和素材注册表；
2. 图片文件按“图片NN.png”映射，不重命名；
3. 文本用真实字体渲染，不把中文写进生成图片；
4. 动效拆成可编辑图层或组件；
5. 预览、检查裁切和字幕安全区后再渲染。

官方入口：

- Anthropic Claude Opus 5: https://www.anthropic.com/news/claude-opus-5

## 其他平台

若平台只支持单张图生视频：把长片拆成片段，使用完整场景或首尾帧逐段生成，再统一剪辑。

若平台支持多图和长提示词：上传当前片段所需图片，并保留全局编号与完整旁白。

若平台支持图层和时间线：透明主体、字幕、箭头、路径和音频应尽量分层，避免一次性烘焙成不可编辑画面。

若平台支持代码动画：优先使用确定性的文字排版、图表、路径和时间轴；生成式视频主要承担真实场景、人物和复杂自然运动。
