# 主题、尺寸与风格决策

只在需要选题、画幅或视觉风格决策时读取本文件。

## 主题筛选

优先选择可以回答“为什么会这样”“它是如何发生的”或“看不见的关系如何影响结果”的主题。

为候选主题检查五件事：

1. 是否能写出一句反常识钩子；
2. 是否存在可拆成3—5步的隐藏机制；
3. 是否有肉眼尺度与微观/系统尺度的视觉变化；
4. 是否能准备清晰的主体图、完整场景或首尾帧；
5. 是否能够用权威资料核验，不依赖夸张结论。

输出主题建议时，每个主题至少给：标题、核心机制、视觉亮点。需要比较时再补传播钩子和事实风险，不要把初步选题直接扩写成完整脚本。

## 画幅预设与自动匹配

| 画幅 | 默认尺寸 | 优先适配 |
|---|---:|---|
| 16:9 | 1920×1080 | 横屏视频、历史长卷、地理迁移、宏大空间、横向时间轴 |
| 9:16 | 1080×1920 | 抖音、视频号、小红书等移动端知识短片，人物、手机和纵向流程 |
| 4:3 | 1440×1080 | 复古档案、教学演示、旧电视或资料片气质、横向信息板 |
| 3:4 | 1080×1440 | 竖版编辑视觉、人物海报、图文叙事、兼顾社交平台封面与正文 |
| 1:1 | 1080×1080 | 方形知识卡片、循环动画、多平台通用物料 |

自动匹配顺序：

1. 用户明确画幅优先；
2. 平台或投放位有硬性比例时服从平台；
3. 无硬性条件时依据叙事方向、人物数量和信息运动方向选择；
4. 两种画幅都合理时，给出“推荐＋备选”，并解释构图差异。

竖屏中把主要人物、机制装置和关键词放在中央80%区域；横屏中为字幕和标题保留上下安全区；4:3与3:4要避免简单裁切16:9或9:16，必须重新安排主体和留白。

## 时长建议

- 30—45秒：一个核心机制、4—5个片段；
- 60—90秒：完整科普闭环、6—8个片段；
- 90秒以上：需要明确章节，不要只增加旁白密度。

## 风格选择方式

具体预设和主题映射见 [style-presets.md](style-presets.md)。

支持四种方式：

- 自动适配：根据主题机制、情绪、时代和画幅选一个主风格，可加一个辅助风格；
- 接受推荐：先给“推荐组合＋选择理由”，用户不反对即沿用；
- 用户点选：用户直接说预设名称；
- 自定义：用户提供参考图或描述配色、字体、材质、人物媒介与动效语言。

用户尚在探索时，只给最匹配的2—3套，不一次展示全部菜单；用户明确要求查看全部预设时再列出十二套。

选定后记录：画幅、主风格、可选辅助风格、主色、强调色、人物媒介、字体、动效语言、完整场景/透明素材分工和主要视觉风险。

如果用户自定义内容与预设接近，可以用预设作为实现基础，但交付时仍标注为“自定义”，不要把用户选择改名成系统预设。
